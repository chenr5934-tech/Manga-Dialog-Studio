# 贴纸库

这个文件夹存放自定义贴纸。工具里「贴纸」面板 →「自定义」分组 →「保存到贴纸库」会把当前自定义贴纸写到这里，「从贴纸库载入」可以把它们读回来。

## 怎么用

1. 顶部点 **贴纸**，切到 **自定义** 分组
2. 点 **导入贴纸图片**，选一张或多张图（透明底 PNG 效果最好）
3. 用着顺手就点 **保存到贴纸库**，起个名字

之后换项目、换浏览器都不影响：文件在磁盘上，点 **从贴纸库载入** 就能取回来。

## 文件格式

每个 `.json` 是一套贴纸：

```json
{
  "name": "我的贴纸",
  "stickers": [
    {
      "id": "custom-xxxx",
      "name": "星星",
      "image": "data:image/png;base64,...",
      "naturalWidth": 256,
      "naturalHeight": 256
    }
  ]
}
```

图片以 data URL 内联在文件里，所以一个文件就是完整的一套，可以直接拷给别人或放进网盘。

## 说明

- 文件名不能包含 `/ \ ..` 等字符，服务端会拒绝这类名称
- 这个文件夹里的 `.json` 不进版本库（见 `.gitignore`），属于个人数据
- 内置的 26 个贴纸是矢量图形，直接编译在程序里，不占用这个文件夹
